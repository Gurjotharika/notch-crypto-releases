# Notch Crypto

Live crypto markets in your MacBook's notch — top coins, trending movers, your watchlist, candlestick charts and price alerts, all in a Liquid Glass panel.

**This repository only hosts downloads and the auto-update feed.** The app's source code is private.

## Download
Get the latest `NotchCrypto-x.y.z.dmg` from the [**Releases**](../../releases/latest) page, open it, and drag **Notch Crypto** into **Applications**.

- Requires **macOS 14 (Sonoma)** or later · Apple silicon & Intel
- First launch: if macOS says the app can't be verified, right-click the app → **Open** → **Open**.

## License
Notch Crypto is a one-time purchase with a lifetime license (activate on up to 2 Macs). Buy a license from inside the app or from the [checkout page](https://checkout.dodopayments.com/buy/pdt_0Nri2RdJR1qnU6OONLEBS?quantity=1); your key arrives by email.

## Updates
The app checks for updates automatically (Settings → Updates). Updates are cryptographically signed. The feed is served from this repo's latest release as `appcast.xml`.

## Privacy
No account, no tracking. Prices come directly from Binance and CoinPaprika; your license key is stored in the macOS Keychain.
